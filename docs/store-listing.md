# Chrome Web Store listing copy

## English

Name: `Cron Dialect Lens`

Short description:

> Explain GitHub Actions and Kubernetes cron schedules directly on GitHub.

Detailed description:

> Cron Dialect Lens adds a small, keyboard-accessible explanation button beside
> cron schedules in GitHub YAML blob and pull request Files changed views. It
> identifies GitHub Actions, Kubernetes CronJob, or uncertain POSIX context;
> shows a natural-language description, schedule and browser timezones, and the
> next five runs; and flags platform-specific mistakes.
>
> GitHub Actions checks include the five-minute minimum, unsupported macros,
> default UTC behavior, adjacent `timezone:`, and possible top-of-hour delays.
> Kubernetes checks include `.spec.timeZone`, controller-dependent schedules,
> supported macros, and invalid embedded `TZ` / `CRON_TZ` values.
>
> Everything is processed locally. No repository content is transmitted or
> stored. The extension has no Chrome API permissions, background service,
> analytics, account, or external API.
